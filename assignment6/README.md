## File structure
* `logs` folder contains .txt files with runtime logs and screenshots of Pkg_J values
* `images` contains the input image used for all convolutions in the report
* `convolve_main.py` contains the code used in Section 1 (setup/convolution) of the report
* `convolve4.py` contains the 3rd iteration on the implementation of convolution that was deemed to not be optimal in Section 1 
* `main_times.py` is the polished script used to gather readings for runtimes
* `main_energies.py` is the polished script used to gather readings for energy
* `plot.py` was used to plot all graphs
